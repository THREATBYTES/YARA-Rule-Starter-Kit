# Security Policy

## Reporting a vulnerability

If you find a security issue in this repository (for example, a fixture that is actually harmful, a rule that could be abused, or a problem in the test tooling), please **report it privately** by emailing **security@threatbytes.dev**. Please do not open a public issue.

Include:
- a description of the issue and its impact
- steps to reproduce
- any relevant file paths, rule names or commit hashes

We aim to acknowledge reports within 3 working days and to keep you informed while we investigate.

## Malware samples

This project never stores live malware. If you believe a file in this repository is malicious, email us straight away and we will remove it.

## Supported versions

Only the latest release on `main` is supported.
